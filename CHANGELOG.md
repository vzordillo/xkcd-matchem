# Changelog

All notable changes to `xkcd-matchem` are documented in this file.

## [0.1.0] - 2026-11-22

### Added
- **Core package & licensing**: Standalone Python 3.10+ package (Apache-2.0 code, CC BY 4.0 documentation and tutorials, SIL OFL 1.1 bundled comic-style fonts `Patrick Hand` and `Comic Neue`, and 15 bundled sample files).
- **Verified physical reference data**: CODATA 2022 constants, IUPAC 2021 / CIAAW standard atomic weights, Blue Obelisk BODR covalent radii, Alvarez (2013) & Mantina et al. (2009) van der Waals radii, and Cromer-Mann (LA-3816) + exact H 1s X-ray scattering form factors.
- **Customizable themes & palettes**: `xkcd_style()` context manager with five built-in presets (`classic`, `notebook`, `poster`, `minimal`, `dark_chalk`), Okabe-Ito colorblind-safe series palettes, Jmol/xkcd/pastel element schemes, inline `{symbol: color}` overrides, `register_preset()`, `register_palette()`, `register_element_palette()`, `style_existing_axes()`, and opt-in `fetch_xkcd_script()`.
- **26 zero-dependency native parsers & strict validation**: XYZ/extXYZ, VASP (`POSCAR`, `CONTCAR`, `XDATCAR`, `DOSCAR`, `EIGENVAL`, `CHGCAR`, `LOCPOT`), CIF (affine symmetry expansion preserving mixed-occupancy species and occupancy metadata), PDB, SDF/MOL (V2000), MOL2, Gaussian `.cube`/`.gjf`/`.log`/`.fchk`, ORCA `.inp`/`.out`, Quantum ESPRESSO `pw.in`/`pw.out`/`bands.dat`/`dos.dat` (explicit cell & unit validation), LAMMPS data (explicit atom styles + `type_map`) & `.lammpstrj` (orthogonal + triclinic), GROMACS `.gro`/`.xvg`, CP2K `.ener`, and xTB `.out`, plus optional adapters for ASE, pymatgen, cclib, RDKit, MDAnalysis, and MDTraj.
- **Scientific geometry & trajectory analysis**: LLL-reduced Gram-bounded closest-vector minimum-image search for skewed triclinic cells, property-preserving `AtomsData.repeat()` supercells, exact spherical-shell periodic `Trajectory.compute_rdf()` (with optional Wigner-Seitz `strict=True`), unwrapped periodic `Trajectory.rmsd()`, continuous Fermi-crossing `BandStructure.band_gap()`, and affine-accurate `VolumetricGrid.slice_mesh()`.
- **xkcd-style plotters & offline 3D Studio**: Depth-sorted 3D structure renderer (`ball_and_stick`, `spacefill`, `stick`, `polyhedra`, unit cells, Miller planes, slab side/trimmed views), 2D skeletal renderer, electronic bands/DOS/MO/CUBE plots, spectroscopy & pure-NumPy powder XRD, reaction/NEB profiles, MD RMSD/RDF/GIF animation (`animate_trajectory`), binary phase hulls, Birch-Murnaghan EOS fits, Pourbaix diagrams, parity/bar/pipeline charts, opt-in millimeter poster layout (`Board`, `Container`, `Card`, `Badge`), offline HTML5 Interactive 3D Studio (`view_structure` / `export_interactive_html`), CLI, animated README demos, and 10 interactive Jupyter Book tutorials.
